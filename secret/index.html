V
001

THE FORMULA

Никакой магии. Только проверки.

Verify состоит из небольших компонентов, которые мы называем Agents . Каждый агент выполняет одну конкретную задачу и передаёт результат системе Verify.

Агент не решает, хороший пользователь или плохой. Он получает определённый сигнал, обрабатывает его и передаёт результат дальше.

RULE №1
Agent получает только те данные, которые необходимы для его задачи.

003 / THE INGREDIENTS

Meet the Agents.

Вот они. Те самые страшные секретные функции, которые находятся внутри Verify.

SA-01
WEB

Session Agent

Следит за жизненным циклом текущей проверки.

WORKS WITH
  • Verify Session ID
  • Discord User ID
  • Discord Server ID
  • Время создания сессии
  • Срок действия сессии
  • Состояние проверки

Session Agent нужен, чтобы одна Verify-ссылка относилась именно к той проверке, для которой она была создана.

Сессия имеет ограниченный срок жизни и после завершения проверки больше не должна использоваться для новой авторизации.

NA-01
NETWORK

Network Agent

Анализирует разрешённые сетевые признаки соединения.

PURPOSE
  • Сетевые сигналы риска
  • Связь с текущей сессией
  • Проверка аномалий
  • Защита от повторных обходов

Network Agent работает только с сетевой информацией, доступной Verify при подключении пользователя.

Один сетевой сигнал сам по себе не является доказательством нарушения и не должен автоматически определять итог проверки.

BA-01
WEB

Browser Agent

Получает ограниченные сигналы из браузерной среды Verify.

PURPOSE
  • Тип браузерной среды
  • Совместимость Web API
  • Согласованность сигналов
  • Технические аномалии

Browser Agent не получает произвольный доступ к содержимому браузера.

Его задача — передать Risk Engine ограниченный набор технических сигналов, используемых непосредственно во время Verify-сессии.

EA-01
ENVIRONMENT

Environment Agent

Проверяет согласованность окружающей среды.

SIGNALS MAY INCLUDE
  • Операционная среда
  • Locale
  • Timezone
  • Доступность функций среды

Environment Agent ищет не «плохие устройства», а необычные сочетания технических сигналов.

Несовпадение одного параметра не должно автоматически приводить к Kick.

DA-01
PLUS

Device Agent

Дополнительные сигналы устройства, доступные Helper или Pass.

AVAILABLE IN
  • Verify Helper
  • Verify Pass
  • Только во время проверки
  • Ограниченный набор сигналов

В отличие от браузера, Helper и Pass могут выполнять локальные проверки среды устройства.

Конкретный перечень используемых полей должен соответствовать текущей версии Verify и политике обработки данных.

IA-01
PLUS

Integrity Agent

Проверяет целостность среды самого Verify Plus.

PURPOSE
  • Helper integrity
  • Pass integrity
  • Версия клиента
  • Состояние Verify-компонентов

Если Verify получает данные от Helper или Pass, ему необходимо понимать, что клиент работает ожидаемым образом.

Integrity Agent относится к состоянию компонентов Verify, а не к личным пользовательским файлам.

PA-01
PASS

Pass Agent

Связывает Verify Pass с текущей проверкой.

PURPOSE
  • Pass identity
  • QR challenge
  • Подтверждение пользователя
  • Текущая Verify Session

Pass не является вечным пропуском на любой сервер.

Он ускоряет повторную Verify Plus проверку и подтверждает конкретный запрос пользователя.

CORE
ENGINE

Risk Engine

Сердце Verify. Но не шпионский суперкомпьютер.

SIGNALS + CONTEXT = DECISION

Risk Engine получает результаты нескольких независимых проверок.

Его задача — оценить их вместе, а не считать один необычный параметр доказательством обхода.
